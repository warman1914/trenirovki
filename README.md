# Тренировки

Лично уеб приложение (PWA) за тренировъчна програма A/B/C (+D): анимирани упражнения, дневник на сериите, таймер за почивка, тегло и прогрес.

- Всички данни стоят в браузъра на устройството (localStorage). Резервно копие: „Прогрес“ → „Изтегли архив“.
- Работи без интернет след първото отваряне (service worker).
- Хостинг: GitHub Pages от клона `main`, папка `/`.

## Файлове
- `index.html` – оформление и стилове
- `app.js` – програма, дневник, прогрес, архив
- `figures.js` – фигурите и позите на упражненията
- `sw.js` – офлайн кеш (при промяна вдигни `CACHE`)
- `manifest.webmanifest`, `icons/` – икона и инсталация
